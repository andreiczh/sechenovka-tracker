# Локальные ресурсы

- **qrcode-generator 2.0.4**, Kazuhiko Arase, MIT. [Исходный проект](https://github.com/kazuhikoarase/qrcode-generator). Browser distribution из npm: `public/vendor/qrcode.js`. Уведомление автора сохранено; текст лицензии — `public/vendor/LICENSE-qrcode.txt`.
- **Golos Text**, `@fontsource-variable/golos-text` 5.3.0, SIL Open Font License 1.1. [Fontsource](https://fontsource.org/fonts/golos-text). Подмножества Cyrillic и Latin, variable weight. Лицензия — `public/fonts/OFL.txt`.
- Иконки PWA — технический временный знак, созданный для этого прототипа; официальные эмблемы организаций не использованы.

Файлы поставляются вместе с сайтом. При открытии страницы запросов к CDN нет.
